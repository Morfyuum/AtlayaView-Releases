# Security Policy

## Supported versions

Only the latest released AtlayaView version is considered supported for security fixes.

## Reporting a vulnerability

Please report security issues privately by e-mail to **AtlayaView@capecter.com**.

When reporting, include:

- the affected AtlayaView version
- the Windows version
- whether the issue affects the Full or FX release
- exact reproduction steps if known
- any relevant screenshots, logs, or proof of concept

You should receive an acknowledgment after review of the report.
